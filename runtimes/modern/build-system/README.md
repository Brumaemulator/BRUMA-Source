# Original BRUMA ARM64 native build
These recipes, requirement data and BRUMA-authored scripts are offered under MIT (LICENSE). The compiled third-party source retains each upstream license. No upstream Android.mk/Application.mk/top-level Makefile is executed.
512 translation units, API 26, NDK 28.2.13676358, C++ shared runtime. arm64-requirements.json records technical source paths, flags and link graph from the previously working compiler commands; CMakeLists.txt is an original implementation, not a copy or translation of undocumented makefile code. This is not a claim of a formal clean-room process.
Use scripts/build-clean-runtime.ps1 for clean locked source/dependency/engine builds; it exports native libraries and does not rebuild the excluded historical Java harness. To build integrated BRUMA use the top-level BUILDING.md and scripts/build-native.ps1 in the complete Corresponding Source kit.
